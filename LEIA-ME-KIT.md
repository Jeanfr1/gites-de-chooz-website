# Les Gîtes de Chooz — KIT COMPLET V3

Version du 11 octobre 2026. Ce dossier est le kit autonome complet : direction, images, scénarios, contenus, données, étude navigable et préparation du QR. Il ne nécessite aucun fichier de la livraison précédente.

## Démarrer

1. Extraire le ZIP dans un nouveau dossier V3.
2. Ouvrir `catalogo.html` : visuels, nouvelle identité So Zen, deux photos de yoga et index complet.
3. Ouvrir `08-estudo/index.html` pour parcourir l’étude. Sélectionner So Zen pour voir les nouveaux éléments.
4. Suivre les scénarios de `06-roteiros`, puis les instructions de `07-integracao`.

Tous les contenus destinés aux visiteurs sont en français.

## So Zen : fichiers actualisés

- `01-identidade/so-zen-logo-transparente.png` : femme en méditation, PNG transparent.
- `05-secoes/so-zen/logo-source.png` : capture fournie par le client.
- `05-secoes/so-zen/yoga-terrasse-01.png` et `yoga-terrasse-02.png` : deux sources photographiques fournies.
- `05-secoes/aba-so-zen.png` : nouvelle direction de la page dédiée.
- `02-direcao/mockup-desktop.png` : accueil avec le nouveau logo et le yoga.

Les sources photographiques sont conservées sans modification ; le cadrage CSS masque l’interface du téléphone. Le PNG du logo conserve les marques visibles de la source. Les mockups sont de la direction visuelle ; l’HTML utilise les photographies réelles.

## Direction approuvée

La palette vert forêt, sauge, lin et laiton, la maquette architecturale, les calques d’animation et les photos des gîtes restent approuvés et sont inclus dans ce kit. Les nouveaux fichiers So Zen sont présentés directement dans le catalogue. Les prompts de cette livraison décrivent uniquement la direction actuelle.

## Points à compléter

Les Gîtes de Chooz est un nom provisoire. Deux gîtes sont actifs ; les deux suivants seront ajoutés plus tard. La propriétaire doit confirmer les consignes spécifiques des séjours. Les dates, prix et modalités du yoga restent à confirmer auprès de So Zen. Le QR final nécessite l’adresse publique définitive.

Modifier uniquement le JSON externe ne met pas à jour l’étude : son JavaScript contient une copie pour fonctionner hors ligne. Aucun site n’a été publié. La revue du HTML dans un navigateur réel reste nécessaire avant production.
